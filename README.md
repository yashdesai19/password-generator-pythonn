# Password Generator & Strength Checker (Python)

## Description
This is a Python-based console application that generates secure random
passwords and checks their strength.

## Features
- Random password generation
- Password strength checking (Weak, Medium, Strong)
- Simple and easy to use

## Technologies Used
- Python
- random module
- string module

## How to Run
1. Install Python
2. Run the file using:
   python password_generator.py

## Learning Outcome
This project helped me understand Python functions, modules,
and basic security concepts.
